# Lab Setup

## Logical architecture

```text
Windows Endpoint
      |
 Wazuh Agent
      |
 Wazuh Manager
      |
 Wazuh Indexer
      |
 Wazuh Dashboard
```

## Setup checklist

- [ ] Deploy Wazuh components.
- [ ] Install and register the endpoint agent.
- [ ] Confirm agent health and connectivity.
- [ ] Enable the required Windows security telemetry.
- [ ] Generate controlled test events.
- [ ] Confirm events appear in the dashboard.
- [ ] Record configuration changes.

## Evidence standard
Screenshots should show the relevant UI state without exposing credentials, tokens, personal data or sensitive network information.

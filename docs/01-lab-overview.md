# Lab Overview

## Purpose
Build a repeatable SIEM workflow using Wazuh and Windows telemetry, with emphasis on the work an L1 SOC analyst performs after an event reaches the dashboard.

## Objectives
- Deploy and validate the Wazuh stack.
- Onboard endpoint telemetry.
- Establish a basic event baseline.
- Investigate security alerts using supporting evidence.
- Record findings in a consistent case format.

## Analyst outcome
Each investigation should answer four questions:

1. What happened?
2. What evidence supports it?
3. How serious is it?
4. What should happen next?

## Scope
Authorised home-lab and educational environments only. No production or unauthorised systems are targeted.

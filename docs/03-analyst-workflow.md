# Analyst Workflow

Use the same sequence for every alert so investigations remain consistent and auditable.

1. **Identify** — alert rule, timestamp, host, user and severity.
2. **Validate** — determine whether the event is expected or anomalous.
3. **Collect** — gather related Windows events, process activity, network indicators and account context.
4. **Correlate** — connect events into a timeline instead of treating a single alert in isolation.
5. **Assess** — determine confidence, impact and urgency.
6. **Decide** — close, monitor or escalate with evidence.
7. **Document** — record the verdict, evidence and recommended next action.

## L1 handoff standard

A good handoff should allow another analyst to understand the case without repeating the entire investigation.

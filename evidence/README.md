# Evidence Library

Store only sanitised screenshots and artefacts that directly support an investigation.

## Naming convention

```text
evidence-01-alert.png
evidence-02-event.png
evidence-03-investigation.png
```

## Quality standard
- Evidence must have a clear purpose.
- Keep timestamps and relevant fields visible.
- Remove credentials, tokens and personal data.
- Do not publish live secrets or unnecessary sensitive network details.
- Link evidence from the relevant case README.
